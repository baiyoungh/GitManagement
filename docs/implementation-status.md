# 实施与验收清单

更新：2026-10-30。此文件记录实际实现和验证状态；上级 `specs/08-roadmap.md` 是原始阶段规划。实现不等于已经完成所有平台人工验收。

## HTTP(S) 凭据交互（2026-11-12，未发布）

- [x] 设置页命名凭据列表、新增/编辑/删除；同服务多账号，SQLite 仅元数据，秘密使用版本化系统钥匙串条目。编辑密码留空保留原值。
- [x] 克隆默认自动认证，可选已保存账号或输入仅本次凭据；缺少凭据时全局弹窗，认证有效后按用户选择保存。HTTP 明示未加密风险，SSH 不显示 HTTP 凭据表单。
- [x] 带任务上下文的临时 credential helper 与鉴权 loopback IPC；系统 helper 仅用于读取，临时输入不转存外部 helper，不修改全局配置。只读克隆连接检查可补填失效凭据，实际 clone 不自动重试。
- [x] 等待认证的取消/迟到回复、进程树回收、排队取消；自动 Fetch 与页面健康检查静默；认证窗口独立排队和焦点层级、事件快照恢复。
- [x] 所选凭据在后台任务读取；自动凭据不可用时可改用临时输入；服务拒绝凭据后，本次应用运行内后续手动操作会询问，不反复自动选择失效凭据。Fetch/Pull/Push 失败后不自动重放，需用户再次执行。远端分支删除接入认证，组合删除先 dry-run 验证远端再删除本地。
- [x] macOS 本地验证：前端 102 项，Rust 111 项（含 9 项真实 Git/应用 helper/本地 HTTP 认证及远端删除保护测试）；类型检查、生产构建；浏览器模拟 IPC 的设置新增、克隆账号选择、960×600 认证叠层及原工作区交互回归。
- [ ] macOS/Windows 实际安装包的系统钥匙串授权、保存/重启读取、安装路径及原生窗口认证验收；本轮自动测试不操作真实系统凭据。
- [x] SSH 密码/私钥口令/主机指纹可视化交互；继续复用系统 OpenSSH 配置与 agent。密码和口令不保存，不自动加入 agent 或写入 Apple Keychain；主机首次信任仅明确核验后交给 OpenSSH 写 known_hosts，变化密钥直接拒绝。

## SSH 认证补充（2026-11-12，未发布）

- [x] 临时 OpenSSH 包装器和 SSH_ASKPASS 通过已有鉴权 IPC 请求三类独立弹窗；未知提示安全拒绝。兼容 OpenSSH 旧/新 SHA256 指纹提示格式，支持端口、IPv6 与含空格密钥路径。
- [x] 强制本次 StrictHostKeyChecking=ask、FingerprintHash=sha256；关闭自动主机密钥更新、自动添加 agent、Apple UseKeychain 保存。后台静默模式 BatchMode=yes，不信任未知主机，不输入秘密。
- [x] 保留用户显式 GIT_SSH/GIT_SSH_COMMAND/core.sshCommand；这些自定义传输不接管，也不保证可视化认证。多因素/任意 keyboard-interactive 提示暂不支持。
- [x] macOS 本地前端 125 项、Rust 123 项全部通过（含 11 项 SSH 集成）：真实系统 OpenSSH/普通用户 loopback sshd 完成首次信任、加密 ed25519 私钥解锁及 Git ls-remote；变化密钥拒绝、取消、静默、IPC 校验、短秘密不破坏 Git 数据等回归。SSH 密码通过真实 askpass 程序与 IPC 验证，未创建系统账号或修改密码以验证服务端密码登录。
- [x] 类型检查、生产构建，960×600 浏览器三类 SSH 弹窗与 HTTP 流程回归。所有 SSH 测试使用临时密钥、配置和 known_hosts，不改动用户 ~/.ssh 或系统钥匙串。
- [ ] Windows/macOS 实际安装包的原生 SSH 弹窗、Windows OpenSSH 版本兼容及服务端密码登录人工验收。

浏览器认证回归为 `scripts/smoke-auth.cjs`（Node 20+，Playwright Chromium；可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定 Chrome），与现有工作区回归一样使用模拟 IPC，不代表原生钥匙串已验收。

## SSH 密钥生成与公钥复制（2026-11-13，未发布）

- [x] 设置新增 SSH 密钥页，发现 ~/.ssh 下的公钥；生成 Ed25519（文件名、备注、口令及二次确认），无口令需显式选择；读取已有 .pub，展示 SHA256 指纹、复制整行公钥和 SSH IdentityFile 示例。
- [x] 私钥永不展示/上传，口令只走临时鉴权 IPC 到 ssh-keygen；固定目录文件名校验、暂存后无覆盖发布、拒绝符号链接及伪装私钥。应用不自动改写 SSH 配置或加入 agent。
- [x] macOS 临时目录的真实应用 helper + ssh-keygen 测试验证加密/无口令、指纹、权限、重复生成保护；前端生成校验/复制回归及 960×600 浏览器布局检查。测试不在用户真实 ~/.ssh 创建密钥。
- [x] 发布部分失败时保留已生成文件并明确提示检查目录，不对最终路径做有竞态风险的删除；ECDSA 公钥额外使用 OpenSSH 验证曲线点，拒绝仅格式正确的无效公钥。
- [x] 本地前端 130 项、Rust 133 项，类型检查、生产构建通过。开发服务热重建期间曾出现 helper 集成超时及一次生成失败；构建稳定后密钥集成连续五轮通过。间歇失败与并行热重建有关的判断尚未独立证明，不沿用失败运行的通过状态。
- [ ] Windows ssh-keygen 提示格式、安装路径与私钥 ACL 实机验收；当前沿用 ssh-keygen 创建的 ACL，不能声称已保证 Windows owner-only 权限。

## 仓库与分支体验补充

- [x] 主按钮在明暗主题下使用独立悬浮背景和文字色，常态/悬浮对比度通过 4.5:1 校验；选中状态悬浮时保留背景。
- [x] 仓库列表两行展示：显示名称在上，实际文件夹、分支和状态在下；名称可通过铅笔按钮、F2 或右键菜单修改，不更改磁盘目录。
- [x] 扫描指定深度内所有目录，包括隐藏目录、依赖目录和仓库内部；深度 1 检查根目录及直接子目录，支持 1–8 层。排除 `.git` 元数据，不跟随目录符号链接，最多返回 2000 个并提示截断。
- [x] 支持普通嵌套仓库、已检出的 Git 子模块和 worktree（`.git` 文件）；已登记仓库不会重复导入，扫描结果标识子仓库。
- [x] 右键仓库可预填路径扫描子仓库；分支弹窗自动扫描最多 8 层，在仓库列表中选择父/子仓库后查看其本地、远端分支和执行分支操作。未登记的子仓库在选中时添加，操作绑定该子仓库。
- [x] 分支弹窗可从已登记子仓库返回同一父仓库下的其他仓库；顶栏名称可打开仓库切换器。
- [x] 本地验证：前端 66 项、Rust 86 项、类型检查、生产构建、macOS 调试应用构建、1440×950 / 960×600 浏览器交互回归。
- [x] macOS 真实项目验收：`base-scaffold-template` 在深度 1 找到 1 个仓库，深度 3 找到 28 个（父仓库及 27 个子仓库）；分支弹窗显示 `hdsmf-service` 独立的本地/远端分支，未修改真实仓库分支。

此处实现的是磁盘上已有仓库的发现与独立管理；尚未检出的子模块（仅在 `.gitmodules` 中声明）初始化、更新、移除仍属 M4 待办。文件夹权限不足时现有扫描会跳过不可读子目录；大目录扫描性能和 Windows 原生交互仍需继续验收。上述功能纳入 v0.1.2 发布。

## 建议后续优先级

1. 编辑草稿持久化与崩溃恢复，外部修改的并排比较/合并。
2. 文件名快速打开、仓库全文搜索、忽略目录筛选、大目录虚拟化。
3. Rollback 前的本地历史/备份（M4 C-11）。
4. 子模块初始化/更新（R-10）、交互式 rebase（L-06）、同步规则导入导出（M-08）。
5. macOS Developer ID/公证与 Windows Authenticode，完成后再接自动更新（T-07）。现有 ad-hoc 签名不等于 Apple 公证。
6. Windows 终端/文件权限与大仓库性能人工验收，补充相关端到端测试。

## 发布约束

普通分支 push（包括 main）不自动触发；PR 运行双平台测试；手动预检运行测试和打包但不发布；仅推送 `v*` tag 触发 GitHub Release。已成功发布版本为 0.1.4，对应 tag `v0.1.4`。后续发布必须遵循 [发布流程](release-process.md)，先确认候选 SHA 的双平台检查，再创建 tag。本次流程及文档调整只推送代码，不创建 tag 或 Release。
