# GitManagement v0.1.6

## 新增

- 凭据管理与 SSH 认证流程：管理 Git 认证信息、SSH 密钥及认证提示。
- 仓库文件管理支持新建文件、新建文件夹、重命名，以及确认后永久删除文件或空文件夹；重命名保留未保存的编辑内容。
- 仓库多选工具栏、右键菜单与分组右键菜单支持批量移除仓库记录。分组操作包含收藏和搜索隐藏的组内仓库，确认框列出范围；保留磁盘文件和分组，部分失败不会中断其他仓库的移除。

## 优化与修复

- 修复浅色、深色主题下编辑器闪烁光标不清晰的问题。
- 优化终端布局、固定新建入口、独立标签关闭按钮及按仓库目录命名；支持重命名、键盘切换、中键关闭、退出后重启和关闭全部后的空状态。
- 终端收起或切换仓库时保留会话；修复最后一个会话关闭后自动重新打开的问题，改善主题配色及窄窗口标签滚动。
- 修复右键文件或文件夹后残留的原生文字选中高亮，保持编辑器文字可选。
- 分支分组与标签标题按层级左对齐，不再随区域宽度居中移动。
- 分支弹窗仅显示当前仓库的分支列表与操作，不再显示左侧仓库栏或自动扫描子仓库。
- 批量操作区数量提示独占标题行，按钮按可用宽度换行，取消多选按钮固定在右上角。

## 验证与限制

- 候选版本使用 `pnpm release:check` 检查版本一致性、前端类型与生产构建、前端全部测试及本机 Rust 测试。
- 双平台测试、预检打包及最终发布状态以此版本候选 SHA 对应的 GitHub Actions 记录为准，不将本机通过等同于跨平台通过。
- 界面预览使用模拟后端，不操作真实仓库；原生桌面界面及 Windows 真机交互尚未复测。
