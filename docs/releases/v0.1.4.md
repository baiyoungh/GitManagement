# GitManagement v0.1.4

## 修复

- Windows 终端测试回应 ConPTY 启动时的光标位置查询，避免等待握手超时。
- 界面保留会话打开调用完成前的终端回应，避免启动阶段丢失握手。
- Windows 关闭终端时使用独立持有的进程句柄，正确处理进程终止结果及已经退出的进程，绕过 portable-pty 0.9 克隆终止器对系统返回值的错误判断。

包含 v0.1.2 的文件编辑、内置终端、子仓库发现与分支管理等全部改动。v0.1.2 和 v0.1.3 的失败发布 tag 保留，安装包由 v0.1.4 的双平台流水线生成。

## 发布结果与后续检查

2026-10-30 双平台测试、打包及 GitHub Release 发布成功，DMG 和 EXE 均已上传。故障细节及验证记录见 [Windows 发布失败复盘](../incidents/2026-10-30-windows-release.md)；下次发布前执行 [发布流程](../release-process.md)。流程文档及预检入口是在发布后补充的，不包含在原有 v0.1.4 tag 中。
