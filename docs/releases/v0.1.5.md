# GitManagement v0.1.5

## 新增

- 变更页支持批量回滚：勾选多个文件后可从工具栏或右键菜单一次性回滚；也可在分组标题上整组回滚。确认框仍会列出文件并单独询问新增/未跟踪文件的处理方式。
- 添加本地仓库和克隆仓库时可填写显示名称；留空时沿用原来的目录名。

## 修复

- 修复分组内的仓库无法拖拽到其他分组或调整组内顺序的问题。现在拖动状态同时保存在内存中，不再依赖 WebKit 在拖拽期间不可靠的自定义数据传输；仓库行整体可拖并补充了 WebKit 样式，Windows 端关闭了会拦截 HTML5 拖放的 Tauri 原生拖放处理器。

## 验证

本地类型检查、前端 69 项测试、Rust 测试与生产构建通过。双平台 CI 测试、预检打包及最终发布以对应提交的 Actions 运行记录为准。
