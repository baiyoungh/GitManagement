# GitManagement v0.1.2

## 新增

- 仓库文件目录树、文件预览与编辑、多文件页签、语法高亮、搜索、撤销和保存。
- 文件保存时检测外部修改，保留 UTF-8 BOM、CRLF/LF 和权限；切换视图保留编辑缓冲，关闭文件或退出时检查未保存内容。
- 内置终端以当前仓库为工作目录启动；按仓库隔离会话，支持调整尺寸、清屏、新建和关闭会话。
- 仓库显示名称可编辑，名称与实际文件夹信息分两行展示，支持铅笔按钮、F2 和右键重命名。
- 目录扫描可按指定 1–8 层深度发现普通嵌套仓库、已检出的子模块和 worktree；已添加的仓库不会重复导入。
- 分支弹窗自动发现子仓库，可分别管理父/子仓库的本地与远端分支，从指定分支创建新分支。

## 修复

- 并排与统一差异视图支持横向滚动；并排模式保持双栏可见，并同步滚动两侧代码。
- 修复亮色外观下有色按钮悬浮后文字难以辨认的问题，并改善暗色外观的主按钮对比度。
- 目录扫描发现父仓库后继续深入，隐藏目录和依赖目录也按指定深度扫描；排除 Git 元数据且不跟随目录符号链接。
- macOS 应用菜单退出和 Cmd+Q 经过未保存编辑检查。

## 验证

- 前端 66 项测试、Rust 86 项测试、类型检查、前端生产构建和 macOS 本地应用构建通过。
- 浏览器交互回归覆盖明暗主题、重命名、子仓库操作目标、文件编辑、终端及 1440×950 / 960×600 布局。
- macOS 真实项目验证指定深度扫描及子仓库本地/远端分支展示。

## 当前限制

- 尚未检出的子模块初始化、更新和移除未实现。
- 编辑草稿暂不支持异常崩溃后的恢复；文件编辑限 UTF-8 文本且不超过 2 MiB。
- 仓库扫描最多返回 2000 个结果，不可读目录会跳过。Windows 新功能仍需真机交互验收。
